# Triage labele

Skillovi govore o pet kanonskih triage uloga. Ovaj fajl povezuje te uloge sa stvarnim imenima labela u issue trackeru ovog repoa.

| Labela u mattpocock/skills | Labela kod nas      | Značenje                                     |
| -------------------------- | ------------------- | -------------------------------------------- |
| `needs-triage`             | `needs-triage`      | Održavalac treba da procijeni issue          |
| `needs-info`               | `needs-info`        | Čeka se da prijavilac doda još informacija   |
| `ready-for-agent`          | `ready-for-agent`   | Potpuno specificiran, spreman za AFK agenta  |
| `ready-for-human`          | `ready-for-human`   | Implementaciju mora uraditi čovjek           |
| `wontfix`                  | `wontfix`           | Neće se raditi                               |

Kad skill pomene ulogu (npr. "apply the AFK-ready triage label"), koristi odgovarajuću labelu iz ove tabele.

Ako počneš da koristiš druga imena labela, izmijeni kolonu "Labela kod nas".
